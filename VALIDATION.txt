- Dead-thesis identity persists. Same-run reincarnation is blocked by structure, not a cooldown.
- TRADE_RETCODE_PLACED fences the campaign as SUBMITTING. No duplicate resend. Late fill attaches.
- WAF/HTML 401/403 is transport. Only an authenticated XauCloud JSON envelope tombstones.
- Cross-terminal manager lease via the XauCloud config envelope (plus same-terminal GlobalVariable).
- Dashboard distinguishes DESIRED vs APPLIED. BRIDGE_NOT_CONFIGURED is never called DELIVERED.
- UNLIMITED is a license entitlement. Customer Settings cannot self-escalate.
- UNLIMITED multiplier UI is hidden: each valid add uses 100% of current remaining capacity.
- Production secret helper refuses default/short secrets. Boot still listens unless APEX_STRICT_SECRETS=1.
- systemd keeps DATA_DIR=/var/lib/xaucloud-apex. Do not set User=xaucloud-apex until that user exists.
