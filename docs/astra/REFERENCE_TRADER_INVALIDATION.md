# Invalidation, weakening and exits

Knowledge version: tradingcartel-breakfast-v1. Exact human stop rules are not recovered; these are evidence-informed thesis distinctions to test prospectively.

NO_SETUP means no coherent location/attempt/failure. REJECTION_PENDING means an extreme was attacked but acceptance/failure is unresolved. THESIS_WEAKENING means the recent proof is being repaired or follow-through is deteriorating. INVALID means the specific contradiction for the current setup has occurred. EXIT is an action on owned exposure, while INVALID can also describe an unentered setup.

For an upper-failure sell, sustained acceptance through the failed region contradicts the original thesis. For a continuation sell, repair/reclaim of the most recent failed rebound and meaningful bullish displacement can contradict the current local entry/add before the distant original peak is reclaimed. A single spread-sized red mark or ordinary pullback is not sufficient. Preserve broad thesis invalidation and each local add's contradiction separately.

An invalid setup identity cannot regain permission merely because a score rises or price revisits the same region. A genuinely new attempt requires a new causal event and renewed assessment. After a loss, no new entry may rely solely on the previous unfulfilled directional expectation. Public Sep26's second narrated buy is the explicit revenge/unconfirmed control.
