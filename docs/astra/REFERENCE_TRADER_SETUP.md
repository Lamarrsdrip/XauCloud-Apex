# Context, location and setup formation

Knowledge version: tradingcartel-breakfast-v1. Read the [master model](REFERENCE_TRADER_MASTER_MODEL.md) before treating any rule below as exhaustive.

## Why this location

A useful upper area is visible before the proposed reversal: earlier high, previous failed advance, the upper end of a strong run, or a failed recovery into a region from which selling already departed. Record how the area was selected using only information then available. A line drawn later is not causal proof of an earlier premarked level. Historical proprietary indicator zones are unknown and may not be substituted with invented formulas.

Original clip1 shows a fast4417→4426 approach and repeated upper tests before downside. Clip3 shows prior high near4057.2, pullback4048–4049, second push above4059, and a sharp response toward4055. Clip5 shows an upper failure near4193, lower rebound peaks and renewed weakness around4189. Clip6 shows a run into4266–4267 followed by a small cluster beneath the rejected top. These differ from a random wick in a range.

The essential formation questions are: what was trying to continue, what area did it attack, did price establish acceptance through it, how did the opposite side respond, and is the current event still fresh? Sweep size, approach velocity, body/range, wick fractions, local pivot changes and overlap are useful measurable features. They are not the strategy by themselves.

## Ordered evidence, multiple shapes

A sweep is a candidate. Failure to accept can develop over multiple bars: return through a level, failed second push, lower high, failed reclaim, or repeated rejection. Do not require every feature to coexist in a single candle. Conversely, a single tiny contrary bar while prior pressure remains intact does not establish meaningful failure.

Continuation setups start from an already established failure. NEW clip8's first visible pre-entry context is bearish M3 with broken shelves, a failed intermediate rebound and a small pause at the local low. No visible upside impulse immediately precedes that first entry. Public Sep6/Sep10 independently support post-rejection lower highs/lows and fresh downside continuation. A previous high sweep can be part of the older thesis, but must not be invented when offscreen.

## What remains hypothetical

Exact significant-level selection, minimum sweep penetration, accepted-close count, setup lifetime, displacement minimum, future target and 'slow/manipulated market' classifier are not recovered. The historical71-bar reference,1.8ATR impulse,0.05ATR sweep and12-minute expiry are Apex implementation settings, not proven trader rules. Maintain separate ages/distances for broad thesis, local reaction, most recent proof and executable quote.
